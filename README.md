## Usage
1. Run the web server from the `dec` directory:
   ```bash
   python3 dec/server.py
   ```
   The page is served from `dec/site/index.html`.
2. Open a browser at [http://localhost:8000](http://localhost:8000) to update the message.
   After saving, the text input will show the stored value.
3. Run `python3 dec/main.py` to print the saved message.
