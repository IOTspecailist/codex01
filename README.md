## Usage
1. Run the web server from the `dec` directory:
   ```bash
   python3 dec/server.py
   ```
   Open a browser at [http://localhost:8000](http://localhost:8000) to set a new message.
2. Save your message through the web form.
3. Run `python3 dec/main.py` to print the saved message.
